# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of F1 Race Replay seriously. If you discover a security vulnerability, please do **NOT** open a public issue.

Instead, please report vulnerabilities by contacting the maintainers privately via email or through GitHub Security Advisories.

Please include:
- A description of the issue and potential impact
- Steps to reproduce or a proof of concept (PoC)
- Any proposed remediation

You can expect an initial response within 48 hours. We will coordinate remediation and disclosure timelines respectfully.
